# 冻结纪律记录（R3 轮）

## 为什么单独记这个

第二轮 Review 的核心流程批评是：**审查对象在漂移**——Reviewer 审查期间 HEAD 前进了 5 个 commit，
导致「按指定范围是 blocker、按 HEAD 已修」的判读歧义。
第三轮必须避免重犯。

## 本轮做法

| 项 | 做法 |
| --- | --- |
| 冻结基准 | `4ae8455` |
| 冻结手段 | `git archive 4ae8455 \| tar -x` → `/tmp/wp2r3-freeze-4ae8455`（无 `.git`，729 文件） |
| 完整性 | `diff -rq` 与 `4ae8455` **逐字节一致** |
| 派审时机 | 冻结完成**之后**才派 Reviewer，并明确告知「审的是冻结副本，不是主仓库」 |
| Reviewer 独立性 | 只读；禁改主仓库；诊断脚本限 `/tmp/wp2r3rev/` |

## 偏离事实（如实记录）

审查进行中，我自己又发现了新问题（`hostMap` 无界增长），并提交了 `97c8eb5`。

**因此当前 HEAD 已不等于冻结基准**：

```
冻结基准：4ae8455
当前 HEAD：97c8eb5   ← 偏离 1 个 commit
```

### 这为什么不影响本轮复审的有效性

- Reviewer 读的是 `/tmp/wp2r3-freeze-4ae8455`，**物理隔离**；
- 我已复核该副本与 `4ae8455` 仍逐字节一致（`diff -rq` 通过），**未被我的后续提交污染**；
- 所以 Reviewer 的结论针对的确实是 `4ae8455`，不是 `97c8eb5`。

### 但这带来一个必须承认的后果

`97c8eb5` 的改动**不在本轮复审范围内**。也就是说：

- 若 Reviewer 判 `4ae8455` 通过，通过的是「不含有界保留」的版本；
- `97c8eb5`（有界保留 + 2 条测试 + M15/M16 变异）**尚未经第三方审查**。

**处理方式**：不把它混进本轮结论。若本轮 APPROVE，则 `97c8eb5` 需要单独一轮复审；
若本轮 REQUEST CHANGES，则把 `97c8eb5` 与本轮问题一起修完，再冻结新基准统一复审。

## 教训

「冻结后再发现问题就顺手改」是**纪律与效率的真实冲突**。
本轮的选择是：**改，但把偏离写明**，而不是压着不发（那样问题会留到下一包）
或假装 HEAD 没动（那是撒谎）。

记录在此，供复审方与后续工作包核对。
